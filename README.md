# Peazy website

Marketing site for Peazy, pricing made easy. Static HTML, hosted on GitHub Pages at https://peazypricing.com.

- `index.html`: overview page (what Peazy does, the platform, value, how to start) and the upside calculator
- `insights.html`, `price-management.html`, `quote.html`, `value.html`: one page per module
- `site.css`, `site.js`: shared styles and navigation for all pages
- `peazy-*.svg`: Lemon P logo files
- `CNAME`: custom domain for GitHub Pages

The previous single-page version is kept on the `archive/site-v1` branch.
